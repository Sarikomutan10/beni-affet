# Beni affeder misin? ❤️

Küçük, romantik ve telefona kurulabilir bir web uygulaması.

- “Hayır” düğmesi yaklaşıldığında kaçar.
- “Evet” seçildiğinde kutlama ekranı açılır.
- Nilüfer — Son Arzum, SoundCloud oynatıcısında başlar.
- GitHub Pages üzerinden otomatik yayınlanır.

## Yerel önizleme

`dist` klasörünü herhangi bir statik HTTP sunucusuyla açabilirsin.

## Müzik

Uygulama telifli müzik dosyası barındırmaz. Parça, SoundCloud üzerindeki yayınından gömülü oynatılır.
